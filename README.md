# HTML Exercises & Mini Projects 🚀

This repository contains my learning journey and practical exercises while exploring the fundamentals of **HTML5**.

The exercises are organized into separate folders, where each folder focuses on applying different HTML concepts through practical implementation.

## 📂 Repository Structure

### 📁 Exercise 1 – HTML Fundamentals & Pizza Poster

This folder contains my initial practice with the fundamental HTML tags and webpage structure.

### Concepts Covered:
- HTML document structure
- Headings (`h1` – `h6`)
- Paragraphs (`p`)
- Anchor tags (`a`)
- Images (`img`)
- Image attributes such as `src`, `alt`, and `width`
- Horizontal line (`hr`)
- Line break (`br`)
- Basic content alignment
- Basic webpage structuring

### 🍕 Mini Project – Pizza Food Poster

As part of the practice, I created a simple **Pizza Food Poster** using HTML fundamentals.

The project helped me understand how different HTML elements can be combined to create a basic webpage.
